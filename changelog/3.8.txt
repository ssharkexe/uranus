Uranus 3.8

Рекомендуется последовательно обновить все magisk-пакеты с флешки

Медиа / Bluetooth
- BT connect не перебивает локальный музыкальный плеер; play/pause с руля и виджета идут в последний до перезагрузки источник.
- Медиа-виджет: прогресс-бар, клик на виджет после перезагрузки открывает последнее приложение.
- Медиа-виджет: добавлен переключатель "локальный источник ↔ телефон (BT)"; переключатель доступен только при подключенном телефоне; обложка для BT источника обновляется стабильнее.
- Фикс зеркалирования BT-метаданных на приборку.

Приглушение медиа на задней преедаче / парктрониках
- Возможность настроить степень приглушения музыки при работе парктроников/задней передачи, по умолчанию — «Минимальная».

Автомобиль
- Настройка Start-Stop в Eco — при вкл функции и переходе в Eco режим выключает старт-стоп.
- Звук выхлопа: вкл/выкл и настройка уровеня (слабый / средний / жёсткий), доступно только в режиме спорт.
- Новый переключатель заслонки выхлопа на виджете Uranus и на кнопках руля.
- Уточнены подписи настроек дворников во вкладке «Автомобиль».
- XCHvac скрыт из «Недавних».
- Исправлена логика автооткрытия шторки при включении зажигания.

XCSettings (опциональный uranus-xcsettings-magisk.zip)
- Патч XCSettings: отключение полноэкранной анимации смены режима вождения по настройке Uranus.

Голос
- Люк: режиме «проветривание» → открытие на 6% ; «люк на N%» — динамический парсер % из голосовой команды как на окнах.
- Голосовой beep не переключает виджет на BT при локальной музыке.

UI / тема / система
- День/ночь: пофикшены баги переключения/автопереключения.
- Превью системных стилей приборки заменены на реальные изображения с приборки (by Krieg).
- Добавлена новая тема приборки (Осень).
- Кнопки руля: подписи Geely/Mode + иконки; подсказки из списков → в «Описание».
- Удалён перехват внешнего USB HID; громкость внешних устройств теперь разрешена в services.jar (by 13thRaven); Нет краша при подключении внешней клавиатуры/dpad.
- Единый каталог конфигов /data/local/uranus/config/ (миграция при обновлении; возможно потребуется второй reboot).
- Логи в системных настройках: общий тумблер + «Собрать все логи».

Я.Навигатор (опциональный uranus-ynavi-magisk.zip)
- Быстрое восстановление геопозиции после зоны плохого GPS: снижены пороги discontinuity/jump.

Uranus.Погода (отдельный APK)
- Надежнее геолокация и reverse-geocode.

Для обновления пакета дождитесь скачивания архива через magisk после нажатия на кнопку "Установить"
